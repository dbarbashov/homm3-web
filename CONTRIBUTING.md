# Contributing

Issues in English or Russian are welcome. Use the in-game report button to attach
a read-only reproduction link, then review and submit the public GitHub issue.
Do not include invitations, seat credentials, private chat or original game files.

This public repository accepts website, JavaScript client and browser test changes.
Run `npm test` before submitting. Engine and server implementation changes are
maintained separately in private repositories. Building a changed C++ runtime
requires maintainer access; a trusted compiled bundle is sufficient for site work.
