# Contributing

Issues in English or Russian are welcome. Use the in-game report button to attach
a read-only reproduction link, then review and submit the public GitHub issue.
Do not include invitations, seat credentials, private chat or original game files.

This public repository accepts website, JavaScript client and browser test changes.
Run `npm test` before submitting. Engine changes belong in the public `homm3-engine` repository and can be built
without an invitation. Native server implementations remain in private
`homm3-lobby`; maintainers run authority integration checks for engine PRs.
A trusted compiled bundle is also sufficient for website-only work.
