# Contributing

Issues in English or Russian are welcome. Use the in-game report button to attach
a read-only reproduction link, then review and submit the public GitHub issue.
Do not include invitations, seat credentials, private chat or original game files.

This repository accepts website, JavaScript client and browser test changes.
Run `npm test` before submitting. Gameplay and rendering changes belong in
[homm3-engine](https://github.com/dbarbashov/homm3-engine). Maintainers run the
additional network integration checks for engine PRs. A trusted compiled bundle
is sufficient for website-only work.
