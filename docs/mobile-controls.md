# Game scale and touch controls

Open **Game menu → Settings → Game scale** to choose 100–200%. The slider and
minus/plus buttons change the size immediately. **Fit to screen** restores 100%.
Your choice stays on this device after reopening the browser.

At 100% the full game fits the available viewport. A larger scale makes the
original interface easier to read and shows a smaller area. Move the enlarged
view with two fingers; taps, one-finger drags and long-press right clicks retain
their normal game behavior. On desktop, the wheel moves the enlarged view and
Shift + wheel moves it horizontally. The site menu remains reachable outside the
scaled game. Rotation and fullscreen changes keep the view within its bounds.

Scaling changes only presentation and pointer mapping, not game rules or the
map’s simulation state. No engine restart or network reconnection is required.
